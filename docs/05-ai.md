# AI Usage

Two angles: AI **in** the product, and AI **in how it was built**. Both should be real and specific; vague "used AI" claims read poorly to engineers.

## In the app (pick one for v1)
- **A. Natural-language grid filters (recommended):** type "top movers over 2% with tight spreads" → an LLM turns it into an AG Grid filter model + sort, shown as editable JSON before applying. Small, useful, shows prompt design + structured output + validation.
- **B. "Explain this move":** select a symbol, get a short summary of the last N minutes of price/volume from the data in the store. Clearly labeled as generated, not advice.
- **C. Anomaly flags:** simple statistical spike detection in the worker (not an LLM). Cheap and fast; can pair with A or B.

Implementation notes:
- API key never in the browser. Calls go through a small Cloudflare Worker proxy with rate limiting.
- Validate the model's output against a schema before touching the grid; fall back gracefully.
- Lazy-loaded so it costs nothing on first paint.
- Cost control: low rate limit, short prompts, demo works without it if the quota runs out.
